# PRÉ-PROJETO DE TRABALHO DE CONCLUSÃO DE CURSO

## 1. Título provisório

**A Influência da Engenharia de Dados na Qualidade dos Dados para Treinamento de Modelos de Machine Learning: uma revisão bibliográfica**

## 2. Tema

Engenharia de Dados aplicada à qualidade, preparação e organização de dados utilizados no treinamento de modelos de Machine Learning.

## 3. Área de concentração

- Engenharia de Software
- Engenharia de Dados
- Inteligência Artificial
- Machine Learning

## 4. Introdução

A utilização de técnicas de Machine Learning tem crescido em diferentes áreas, com aplicações em sistemas de recomendação, saúde, educação, finanças, segurança e processos de tomada de decisão. Entretanto, a qualidade dos resultados produzidos por esses sistemas está relacionada não somente ao algoritmo utilizado, mas também às características dos dados empregados em seu desenvolvimento e treinamento.

Dados incompletos, inconsistentes, pouco representativos ou que contenham padrões enviesados podem influenciar o comportamento dos modelos de aprendizagem de máquina. Dessa forma, etapas relacionadas à coleta, organização, limpeza, transformação, validação e preparação dos dados assumem importância no desenvolvimento de sistemas baseados em Machine Learning.

Essa discussão também se relaciona aos problemas observados em sistemas contemporâneos de Inteligência Artificial. Na palestra que motivou este estudo, é destacado que um modelo pode apresentar desempenho aparentemente elevado durante sua avaliação e, ainda assim, carregar vieses presentes nos dados utilizados em seu treinamento, especialmente quando aplicado a indivíduos ou contextos diferentes daqueles representados no conjunto de dados original.

A palestra também chama atenção para situações em que modelos aprendem padrões presentes nos dados de treinamento que não correspondem necessariamente ao fenômeno que se deseja analisar, produzindo resultados coerentes ou aparentemente precisos sem garantir que o comportamento aprendido seja generalizável.

Nesse contexto, este trabalho pretende analisar, por meio de uma revisão bibliográfica, como as práticas associadas à Engenharia de Dados e à qualidade dos dados influenciam o desenvolvimento e o treinamento de modelos de Machine Learning.

## 5. Problema de pesquisa

**Como as práticas relacionadas à qualidade, preparação e organização dos dados influenciam o treinamento e a confiabilidade de modelos de Machine Learning segundo a literatura científica?**

## 6. Hipótese

A literatura científica indica que práticas de Engenharia de Dados relacionadas à preparação, qualidade, organização, validação e documentação dos dados contribuem para a melhoria da confiabilidade dos conjuntos de dados utilizados no treinamento de modelos de Machine Learning, podendo influenciar seu desempenho, capacidade de generalização e ocorrência de vieses.

## 7. Objetivo geral

Analisar, por meio de uma revisão bibliográfica, a influência das práticas de Engenharia de Dados na qualidade dos dados utilizados para o treinamento de modelos de Machine Learning.

## 8. Objetivos específicos

1. Apresentar os principais conceitos relacionados à Engenharia de Dados e ao Machine Learning.

2. Identificar, na literatura científica, os principais aspectos associados à qualidade dos dados utilizados no treinamento de modelos de Machine Learning.

3. Investigar a importância de etapas de preparação, limpeza, transformação e validação dos dados para sistemas de aprendizado de máquina.

4. Analisar como problemas relacionados à qualidade e à representatividade dos dados podem contribuir para vieses e limitações na generalização dos modelos.

5. Identificar práticas de Engenharia de Dados apontadas pela literatura como relevantes para a obtenção de dados mais adequados ao treinamento de modelos de Machine Learning.

6. Discutir a relação entre qualidade dos dados, desempenho, generalização e confiabilidade dos modelos.

## 9. Justificativa

A relevância desta pesquisa está relacionada ao crescimento da utilização de sistemas de Inteligência Artificial e Machine Learning e à necessidade de compreender os fatores que influenciam a qualidade desses sistemas.

É comum que discussões sobre Machine Learning estejam concentradas nos algoritmos, arquiteturas e métricas de avaliação dos modelos. Entretanto, o processo de construção de um sistema de aprendizagem de máquina depende de uma cadeia anterior de atividades relacionadas aos dados. A coleta, integração, tratamento, transformação, seleção e validação dos dados podem influenciar diretamente aquilo que será aprendido pelo modelo.

A questão torna-se ainda mais relevante quando são considerados problemas como viés, correlações inadequadas, baixa representatividade e mudanças nas características dos dados. Um sistema pode apresentar bons resultados em determinado conjunto de avaliação e ainda assim apresentar limitações quando utilizado em condições diferentes das observadas durante seu treinamento. Essa preocupação é destacada na palestra utilizada como motivação para o presente trabalho, que enfatiza a possibilidade de modelos apresentarem desempenho elevado nos testes e reproduzirem, simultaneamente, características enviesadas existentes nos dados de treinamento.

Diante disso, investigar o papel da Engenharia de Dados na qualidade dos dados utilizados por modelos de Machine Learning pode contribuir para uma compreensão mais ampla do processo de desenvolvimento desses sistemas, deslocando parte da atenção do algoritmo isoladamente para todo o ciclo de preparação dos dados.

A pesquisa também se justifica academicamente pela existência de estudos que discutem qualidade de dados, pré-processamento, vieses algorítmicos, representatividade, generalização e confiabilidade de sistemas de Machine Learning, permitindo reunir e analisar essas contribuições em uma perspectiva integrada de Engenharia de Dados.

## 10. Metodologia

A pesquisa será caracterizada como uma **revisão bibliográfica**, de natureza qualitativa e caráter exploratório.

Inicialmente será realizada uma revisão da literatura relacionada aos seguintes temas:

- Engenharia de Dados;
- qualidade de dados;
- preparação e pré-processamento de dados;
- Machine Learning;
- viés em dados e algoritmos;
- representatividade dos dados;
- generalização de modelos;
- correlações espúrias;
- data leakage;
- confiabilidade de sistemas de Inteligência Artificial.

A busca bibliográfica será realizada em bases e mecanismos de pesquisa acadêmica, priorizando fontes científicas nacionais e internacionais, tais como SciELO, Google Scholar, IEEE Xplore, ACM Digital Library, ScienceDirect, SpringerLink e repositórios de universidades brasileiras.

Serão priorizados trabalhos publicados em português e estudos brasileiros relacionados ao tema, sem excluir referências internacionais consideradas relevantes para a fundamentação teórica.

Como critérios de inclusão, serão considerados trabalhos que:

- abordem qualidade ou preparação de dados para Machine Learning;
- discutam vieses relacionados aos dados ou aos modelos;
- apresentem relações entre qualidade dos dados e desempenho ou generalização;
- tratem de práticas de preparação, organização, documentação ou validação de dados;
- apresentem contribuição relevante para a compreensão do ciclo de desenvolvimento de sistemas de Machine Learning.

Serão excluídos trabalhos que não apresentem relação direta com o problema de pesquisa, materiais sem caráter acadêmico ou estudos cujo conteúdo não contribua para os objetivos estabelecidos.

Após a seleção, os trabalhos serão analisados de forma comparativa e organizados por categorias temáticas, buscando identificar convergências, divergências e lacunas na literatura.

## 11. Eixos temáticos da revisão

A revisão bibliográfica será organizada principalmente nos seguintes eixos:

### 11.1 Engenharia de Dados

Conceitos, processos e práticas relacionados à coleta, integração, armazenamento, transformação e preparação dos dados.

### 11.2 Qualidade dos dados

Dimensões da qualidade dos dados relevantes para aplicações de Machine Learning, como completude, consistência, precisão, relevância, atualidade e confiabilidade.

### 11.3 Preparação dos dados

Limpeza, transformação, normalização, tratamento de dados ausentes, seleção de atributos e demais procedimentos de preparação.

### 11.4 Viés nos dados

Formas pelas quais características presentes nos dados podem influenciar modelos e produzir resultados sistematicamente inadequados.

A palestra utilizada como motivação enfatiza justamente que sistemas podem reproduzir padrões presentes nos dados históricos de treinamento, inclusive quando tais padrões representam problemas existentes no processo de origem.

### 11.5 Representatividade e generalização

Relação entre a distribuição dos dados de treinamento e a capacidade do modelo de produzir resultados adequados em novos contextos.

### 11.6 Correlações espúrias e aprendizado de padrões inadequados

Estudos sobre situações em que o modelo aprende características relacionadas aos resultados observados nos dados, mas que não representam necessariamente o fenômeno que se pretende modelar.

### 11.7 Confiabilidade dos modelos

Relação entre qualidade dos dados, avaliação dos modelos, robustez, generalização e confiabilidade das aplicações de Machine Learning.

## 12. Resultados esperados

Espera-se identificar, na literatura científica, os principais fatores relacionados à qualidade dos dados que influenciam o desenvolvimento e o treinamento de modelos de Machine Learning.

Também se espera sistematizar as principais práticas de Engenharia de Dados associadas à preparação e validação dos dados e discutir sua relação com:

- desempenho dos modelos;
- capacidade de generalização;
- reprodução de vieses;
- confiabilidade dos resultados.

Ao final, pretende-se apresentar uma síntese da literatura que evidencie a importância da etapa de dados no ciclo de desenvolvimento de sistemas de Machine Learning, contribuindo para uma compreensão mais ampla do papel da Engenharia de Dados nesse processo.
